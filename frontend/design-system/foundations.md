# 基础规范

本文件说明如何使用 [`tokens.css`](./tokens.css) 中的数值。目标是还原 AgenticOS 的轻量企业级桌面界面：浅灰蓝画布、白色工作卡片、蓝紫主色、克制边框和高信息密度。

## 字体与标题

所有界面使用 `--font-sans`。代码、ID、SQL 和结构化技术值使用 `--font-mono`，普通英文或数字不切换等宽字体。

| 语义 | token | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | `--font-size-xl` | `--font-weight-semibold` | 工作卡片头部的唯一页面标题 |
| 区块标题 | `--font-size-md` | `--font-weight-semibold` | 表单段落、卡片组和详情分区 |
| 组件标题 | `--font-size-sm` | `--font-weight-medium` | 指标卡、图表、弹窗小节 |
| 正文 | `--font-size-sm` | `--font-weight-regular` | 描述、表单标签、表格内容 |
| 强调正文 | `--font-size-md` | `--font-weight-medium` | 关键名称、重要操作和值 |
| 辅助文字 | `--font-size-xs` | `--font-weight-regular` | 时间、说明、元数据和紧凑状态 |
| 指标数字 | `--font-size-metric` | `--font-weight-semibold` | 监控和总览中的核心数值 |

页面中只出现一个最高层页面标题。独立原型可使用 `h1`；嵌入完整产品壳层时，如果产品级标题已占用 `h1`，页面标题使用 `h2`，但视觉仍使用页面标题 token。页签名称不是标题，卡片标题不与页面标题争夺层级。中文正文使用正常字距，标题可轻微收紧但不使用装饰字体。

## 颜色语义

- `--color-bg` 是全局工作区画布，`--color-card` 是主要内容表面；不要用多个近似白色制造层级。
- `--color-primary` 只表达当前选择、主操作、焦点和品牌识别。大面积背景使用 `--color-primary-light`。
- 正文按 `text`、`text-secondary`、`text-tertiary` 三层使用；禁用文本使用 `--color-disabled-text`。
- success、warning、error、info 表达业务状态，不用于装饰。状态必须同时有文字或图标，不能仅依赖颜色。
- 图表按 `--chart-1` 至 `--chart-8` 顺序取色；正负和告警数据优先使用对应语义色。

## 桌面壳层

目标站点的 41 个采集状态在参考视口中具有同一几何关系：固定顶栏、固定左侧导航、20px 工作区边距和占满剩余区域的主卡片。实现时直接使用 `--shell-*` tokens。

```text
┌────────────────────────────── 顶栏 ──────────────────────────────┐
│  品牌 / 全局导航                         搜索 / 通知 / 用户       │
├────────── 侧栏 ─────────┬────────────────────────────────────────┤
│ 一级模块与二级菜单       │  工作区边距                            │
│                         │  ┌──────── 主内容卡片 ───────────────┐ │
│                         │  │ 页面头部 / 页签 / 内容             │ │
│                         │  └───────────────────────────────────┘ │
└─────────────────────────┴────────────────────────────────────────┘
```

壳层规则：

- 顶栏和侧栏固定，工作区独立滚动；
- 主内容卡片在工作区内全宽、全高，内部再划分固定头部、页签和可滚动内容；
- 页面标题区包含图标、标题和一句描述，主要操作可放在右侧；
- 1440×900 是视觉回归基准，不是固定画布；窗口变窄时优先保住导航、工具栏操作和数据表可用性；
- 低于 `--shell-min-width` 时允许水平滚动，不另行切换移动端导航。

## 间距与局部网格

使用 4px 基础序列，不强制全局 12 栏。

- 页面边距使用 `--shell-page-inset`；
- 卡片和主要分区以 `--space-5`、`--space-6` 为主；
- 表单控件、标签和紧凑工具栏以 `--space-2`、`--space-3` 为主；
- 分区之间用 `--space-6` 或 `--space-8`；
- 4px 只用于图标、徽标和紧凑组件内部微调，不作为页面主间距。

局部网格按内容选择：

- 双栏：配置表单、主次详情、左右对比；
- 三栏：指标卡、能力卡、同级摘要；
- 四栏：仅用于短指标，空间不足时降为两栏；
- 树表和目录：左侧固定或受控宽度，右侧弹性占满；
- 表格：保持单一宽内容区，需要时在表格容器内部横向滚动。

## 形状、边框和阴影

主卡片使用 `--radius-xl` 与 `--shadow-card`；普通控件和内部卡片使用 `--radius-lg`；紧凑标签使用 `--radius-sm` 或 `--radius-pill`。同一组件的不同状态保持相同圆角。

默认层级主要依靠表面与边框，阴影保持克制。只有弹窗、抽屉和悬浮菜单使用明显浮层阴影。

## 图标与动效

使用线性图标，常规描边约 1.75–2px。图标必须服务于识别和状态，不在每段文字旁装饰性重复。

交互过渡使用 `--duration-fast` 或 `--duration-normal`，仅作用于颜色、透明度、阴影和小范围位移。加载状态允许旋转，避免持续发光或大面积背景动画。系统自动尊重 `prefers-reduced-motion`。

## 可用性底线

- 标准表单和主要操作使用中号控件；系统管理工具栏、表格操作和分页允许使用小号控件，以保持目标系统的桌面信息密度；
- 图标按钮至少使用小号控件的点击区域，只有纯文本行内操作可按文字内容收紧；
- 所有键盘可操作元素有可见焦点；
- 表单标签、错误信息和帮助文本与控件建立明确关系；
- 破坏性操作使用 error 语义并二次确认；
- 空、加载、错误、禁用和无权限状态都必须设计，不能只提供理想状态。
