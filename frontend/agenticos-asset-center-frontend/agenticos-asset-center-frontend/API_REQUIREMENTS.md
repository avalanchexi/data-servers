# 资产中心接口需求说明

本文件只描述前端需要的后端能力，不包含后端实现。资产中心主接口统一以 `/api/v1/asset` 为前缀，列表接口通常需要返回 `{ items, total }`，并接受 `limit`、`offset` 及页面对应的筛选参数。

## 核心接口域

| 接口前缀 | 用途 | 主要能力 |
| --- | --- | --- |
| `/overview` | 资产总览 | 资产全景统计、健康评分、排行榜、问题看板 |
| `/map` | 数据地图 | 资产检索、热门排行、详情、数据预览、资产报告、访问量记录 |
| `/collect` | 元数据采集 | 采集任务增删改查、运行/停用、执行日志 |
| `/catalog` | 资产目录 | 资产清单、物理 Catalog、数据源绑定、类目树、权属、估值、订单、使用统计 |
| `/standard` | 数据标准 | 标准集、标准代码、命名词典、字段映射、智能推荐、覆盖率 |
| `/quality` | 数据质量 | 规则模板、质量规则、规则执行、检查结果、复检、SLA 报告、质量评分 |
| `/security` | 数据安全 | 数据分级、AI 自动打标、脱敏策略、访问控制、审计日志 |
| `/lifecycle` | 生命周期 | 分层存储策略、归档/销毁执行单、审批与状态流转、留痕证据 |
| `/service` | 数据服务 | 服务注册、发布/下线、MCP 发布、调用统计、外部数据登记 |
| `/dcmm` | 治理评估 | DCMM 指标、自评、证据、制度、战略目标、治理组织、领域驾驶舱 |
| `/architecture` | 数据架构 | 数据模型、数据分布、集成共享情况，只读聚合 |
| `/governance` | 治理中心 | 治理问题列表、资产 360 详情，只读聚合 |

## 资产中心之外的关联接口

| 接口 | 被哪个页面使用 | 用途 |
| --- | --- | --- |
| 数据源列表接口 | 资产目录、采集任务 | 选择需要绑定或采集的数据源 |
| 数据集列表接口 | 数据服务注册 | 选择服务关联的数据集 |
| 语义模型列表接口 | 数据服务注册 | 选择服务关联的语义模型 |
| 角色列表接口 | 数据安全 ACL | 给角色配置资产访问权限 |
| `/api/v1/governance-agent/*` | 总览问题看板、治理评估 | 治理建议对话、方案应用、历史记录、规则扫描 |
| `/api/v1/security-eval/*` | 安全合规评测 | 评测题库、运行记录、启动评测、结果导出 |
| `/api/v1/security-redteam/*` | 安全红队 | 语料统计、运行记录、启动测试、结果导出 |

## 对接约定

- 鉴权：前端 Axios 拦截器沿用登录态，后端需对写接口实施权限校验。
- 错误：建议返回可读的 `detail` 或 `message`，前端会从这两个字段提取错误文案。
- 分页：建议统一使用 `limit + offset`，响应返回 `items + total`。
- 状态流转：审批、发布、归档、销毁等操作由专用 status/approve 接口完成，不通过前端直接改状态字段。
- 流式能力：治理 Agent、安全评测和红队运行使用 `fetch` 读取 SSE/流式响应。

更细的请求参数和响应类型可参考 `src/api/asset.ts` 及相应页面调用位置；这些文件属于前端请求封装，不是后端代码。
