# 综合三云逻辑表创建管理与资产展示差异

Type: research
Status: resolved
Parent: ../map.md
Blocked by: 01, 02, 03

## Question

综合三家已核验官网资料，形成统一但不失真的对象映射、创建／管理／使用流程对照、过程字段与数据资产列表／详情字段矩阵、关键差异与证据缺口；保留官网原词、直接 URL、访问日期与页面／官方截图证据，并明确哪些结论可以转化为本仓库数据服务平台的产品设计输入，哪些仅是竞品观察。最终写入 `docs/research/logical-table-creation-and-asset-view-comparison.md`。

## Answer

已完成三家官网一手来源综合。结论不是三家共享同一种逻辑表：Dataphin 是规范建模与生产任务对象，DataArts Studio 的逻辑实体是业务语义对象，DataLeap 的逻辑表是物理表与 API 之间的虚拟映射。报告分别还原了创建、管理、使用、过程字段，并把资产页拆成 Dataphin 资产清单/资产目录、DataArts 业务资产/技术资产、DataLeap 逻辑表集市，所有字段按正文、截图、API 和未证实四档记录。

最终报告：[`docs/research/logical-table-creation-and-asset-view-comparison.md`](../../../docs/research/logical-table-creation-and-asset-view-comparison.md)
