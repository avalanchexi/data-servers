# 三云中台逻辑表竞品调研地图

Label: wayfinder:map

## Destination

形成一份可直接支持本仓库数据服务平台设计的中文、官网可追溯调研：分别还原阿里云 Dataphin、华为云 DataArts Studio、火山引擎 DataLeap 中与“逻辑表”最接近对象的创建、管理与使用过程，逐项盘点过程字段以及三者数据资产页面展示的信息，最后给出严格区分官方事实、跨产品映射与本项目建议的横向结论。

## Notes

- 本地图按用户要求携带调研执行，最终产物写入 `docs/research/logical-table-creation-and-asset-view-comparison.md`；不修改产品代码或原型。
- 三家产品按仓库同批调研文档固定为阿里云 Dataphin、华为云 DataArts Studio、火山引擎 DataLeap；DataWorks 不进入主对比。
- “逻辑表”是比较口径，不预设三家对象同义；必须保留官网原词，并说明逻辑表、逻辑实体、事实表、维度表、汇总表、物理表等边界。
- 事实调研使用 `$research`，优先产品官网、官方帮助文档、官方 API 与官网页面截图；搜索摘要和第三方文章只能用于定位，不能作为结论证据。
- 每家都回答四组问题：创建链路、管理链路、使用链路、创建表单及数据资产列表／详情页字段。页面字段无法从公开资料确认时，明确标记“公开官网未证实”，不得推测成事实。
- 保留可复核采证结果：官网原词、页面路径、直接 URL、访问日期、页面可见截图或官方截图线索；截图中可见但正文未明确说明的字段单列为“页面观察”。
- 官方页面可能随版本、区域、控制台权限变化；记录调研日期、来源 URL、页面更新时间（如可见）及证据限制。
- 领域语言以 [`CONTEXT.md`](../../CONTEXT.md) 为准，但本次不因外部竞品术语直接修改项目术语表。

## Decisions so far

- [调研阿里云 Dataphin 的逻辑表流程与资产信息](issues/01-research-alibaba-dataphin.md) — Dataphin 的逻辑表是规范建模与生产任务对象；资产清单是治理元数据入口，资产目录只展示已上架资产，两类页面必须分开比较。
- [调研华为云 DataArts Studio 的逻辑表流程与资产信息](issues/02-research-huawei-dataarts.md) — DataArts 的对齐对象是“逻辑实体（即逻辑表）”；发布后可同步为业务资产，也可转换为物理模型，业务资产与技术资产必须分视角呈现。
- [调研火山引擎 DataLeap 的逻辑表流程与资产信息](issues/03-research-volcengine-dataleap.md) — DataLeap 的逻辑表是物理表与 API 之间的虚拟映射；逻辑表集市是可证实的跨项目发现页，通用数据地图是否收录 OneService 逻辑表尚无官网证据。
- 三家同名对象处于不同语义层级，最终对比按“对象定位—创建—管理—使用—资产发现”展开，不把流程强行合并成一条通用生命周期。
- 资产字段按“官网正文明确、官方截图观察、官方 API 存在但 UI 未证实、公开资料未证实”四档记录。
- [综合三云逻辑表创建管理与资产展示差异](issues/04-synthesize-logical-table-comparison.md) — 已形成完整对比报告，并将可直接支持本仓库逻辑表原型的信息架构与仍需真实租户确认的证据缺口分开保留。

## Out of scope

- 购买、开通或写入任何云账号资源；不实际创建生产逻辑表。
- 非公开控制台中的租户定制字段、企业私有元数据和无法由官方资料验证的行为。
- 三家产品的价格、部署架构、全量功能对比，以及与逻辑表无关的数据治理能力。
