# 确定 HTML 原型的设计与交付契约

Type: grilling
Status: resolved
Parent: ../map.md
Blocked by: 01

## Question

确定原型设计规范 Skill 对 HTML 原型作出的统一承诺：单文件或多文件、离线依赖、字体回退、标题层级、页面宽度、栅格、间距、响应式断点、主题、组件状态、交互反馈、数据与文案、键盘操作和可访问性分别需要达到什么标准；同时明确哪些规则必须遵守、哪些允许按原型场景调整。

## Answer

原型设计规范 Skill 对 HTML 原型采用以下统一交付契约：

1. **文件与依赖**：默认交付一个自包含 `.html` 文件，CSS 和 JavaScript 内联，不依赖 CDN、远程字体、远程图片或在线组件库；只有用户明确要求时才拆为多文件。文件应能离线直接打开，并完成原型展示的主要交互。
2. **桌面 Web 边界**：只面向桌面 Web，不承担平板、移动端或触屏适配。以 `1440×900` 为主要设计与验收视口，并在常见桌面宽度内保持可用；内容最大宽度 `1440px`，页面外边距 `24px`，12 栏栅格，沟槽 `16px`。普通页面不得产生整体横向溢出，宽表格只允许在表格容器内部滚动。不为 `992px` 以下视口设计折叠、重排或移动端导航。
3. **字体与层级**：只使用本地系统字体回退，不下载远程字体；正文 `14px`、辅助文字 `12px`、模块标题 `16px`、页面标题 `20–24px`，正文权重 `400`，标题和选中态主要使用 `500`。使用语义化 `h1–h3`，不得只靠字号模拟标题。
4. **尺寸与视觉**：以 `4px` 为主要间距基准并允许 `2px` 精细调整，默认控件高度 `32px`。颜色、间距、圆角、阴影、动效和组件尺寸统一引用品牌中立的 `design-tokens.css`，不得在页面中另建平行 token 或使用第三方品牌变量名。
5. **组件与交互**：使用语义 HTML；已展示的组件覆盖适用的 hover、active、focus、disabled、loading 和 error 状态。导航、筛选、分页、表单校验、步骤切换、弹窗和主题切换等已展示动作必须可操作。同一任务区域只保留一个主操作，危险操作二次确认，成功、错误、空状态和无权限状态提供明确下一步；不实现原型场景没有展示或验证价值的后台逻辑。
6. **主题与内容**：默认浅色，只有用户明确要求时才通过语义 token 提供暗色。示例使用真实、简洁的中文业务文案，不使用 Lorem ipsum，不出现第三方 Logo、品牌名称、品牌宣传文字或品牌化示例。
7. **图标**：不使用 emoji 充当界面图标；离线原型可以使用风格一致、品牌中立的内联 SVG。装饰图标设为 `aria-hidden`，独立图标按钮提供可访问名称。
8. **可访问性**：正文对比度至少 `4.5:1`，使用原生交互元素并提供清晰的 `:focus-visible`；表单标签、错误信息与控件正确关联；颜色不是唯一的状态表达；支持 `prefers-reduced-motion`；桌面交互目标至少 `32px`。完整 Tab 顺序、焦点陷阱、焦点归还和纯键盘路径只在任务明确要求键盘可访问性时实现；不要求触屏目标尺寸或移动端触控适配。
9. **可调整项**：页面密度、侧栏形式、卡片数量、数据量、页面模式和是否提供暗色主题可按具体原型场景调整；文件自包含、桌面边界、token 一致性、语义层级、组件状态、核心交互、品牌清理和基础桌面可访问性属于必须遵守的规则。
