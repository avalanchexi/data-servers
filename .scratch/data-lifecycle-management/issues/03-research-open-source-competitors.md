# 筛选并调研高关注度开源数据治理项目

Type: research
Status: open
Parent: ../map.md
Blocked by: none

## Question

从 GitHub 上筛选 1–2 个社区关注度高、持续维护、官方资料充分且与本项目数据生命周期治理相关的开源项目，优先比较能够补足国内云厂商资料中元数据事件、所有权、质量、使用分析、变更影响、策略、归档或删除治理缺口的平台。

必须记录筛选日期、官方仓库、当时可见的 Star／活跃度信号和选择理由；随后基于官方文档与源代码，分析其核心对象、生命周期事件／状态、策略与工作流、血缘影响、质量／安全集成、使用与成本指标、删除或退役语义、扩展机制及明确缺口。不得把“元数据删除”误写成“物理数据销毁”，也不得因项目高 Star 就假定具备完整 DCMM 能力。完整结果写入 `docs/research/data-lifecycle-open-source-competitors.md`。
