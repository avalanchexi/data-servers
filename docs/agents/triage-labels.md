# 分流标签

工程技能使用五种标准分流角色。本文件将这些角色映射到本仓库议题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此议题 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经明确，可交由自主代理处理 |
| `ready-for-human` | `ready-for-human` | 需要由人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某种角色时，例如“应用可交由代理处理的分流标签”，应使用此表中对应的标签字符串。

如需匹配现有标签体系，请修改右侧“本仓库中的标签”列。
