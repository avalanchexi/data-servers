# 布局与栅格

## 支持边界

- 只支持桌面 Web；主要验收视口为 `1440×900`。
- 页面应在常见桌面宽度内可用，低于 `--ds-desktop-min` 的平板或移动端布局不在范围内。
- 不增加移动端导航、卡片重排或触控专属交互。

## 页面壳层

- 顶部导航使用 `--ds-nav-height`，侧栏建议使用 `--ds-sidebar-width`。
- 内容区域使用 `--ds-content-max`，桌面外边距使用 `--ds-page-padding`。
- 页面使用 12 栏栅格，栏间沟槽使用 `--ds-grid-gutter`。
- 区块纵向间距优先使用 `--ds-space-7/8/9/10`。
- 画布与容器形成清晰两层背景，不用阴影堆叠每个卡片。

## 信息层级

1. 页面标题、说明和全局主操作。
2. 影响当前页面的数据摘要或关键提醒。
3. 搜索、筛选和局部操作。
4. 主数据、表单或任务内容。
5. 分页、补充说明和次要链接。

## 溢出规则

- 支持的桌面视口不得出现页面整体横向滚动。
- 宽表格放在明确的 `.table-scroll` 容器中，只让表格区域滚动。
- 操作列保持可识别；不要为塞入更多列压缩到不可读。
- 长文本优先限定宽度并提供完整查看路径。
