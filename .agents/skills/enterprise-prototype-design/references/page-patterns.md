# 页面模式

只读取当前原型对应的模式。

## 工作台

顺序采用：关键概览 → 趋势或重点任务 → 快捷操作和最近动态。摘要卡只保留能驱动行动的指标，避免纯装饰数据。

## 列表页

顺序采用：页面标题与创建动作 → 搜索/筛选 → 表格操作栏 → 数据表格 → 分页。筛选、空状态、错误反馈和详情查看必须可操作。

## 表单页

按用户任务组织字段，不按数据库表组织。长任务使用清晰步骤：基本信息 → 配置 → 确认。提交前允许检查；错误紧贴字段；动作区位置稳定。

## 详情页

先展示对象名称、主状态和关键动作，再展示概览、契约或配置，最后展示历史与审计。危险动作与普通编辑分离。

## 登录页

仅在任务明确要求登录原型时使用。表单保持紧凑，错误说明恢复路径；不得加入第三方 Logo、品牌锁定区或宣传文案。
