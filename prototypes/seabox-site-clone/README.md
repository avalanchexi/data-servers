# Seabox 整站前端静态仿真原型

本项目依据只读 Playwright 采集清单和现场设计系统报告，生成一组可浏览的整站前端 HTML。业务记录全部为仿真数据，不连接源站接口。

## 内容

- `001-*.html` 至 `142-*.html`：与采集到的 142 个页面或页内标签状态逐一对应。
- `index.html`：默认打开“资产总览”。
- `page-manifest.json`：HTML 文件、源路由模板、左侧导航来源和页面类型的映射清单。
- `src/`：共享 React 页面外壳、组件、样式与生成后的页面配置。
- `dist/client/`：生产构建后的 142 个页面和 `index.html`，全部资源位于本地。
- `qa/`：Playwright 验证结果、实现截图及源站同屏对比证据。

## 本地浏览

在本目录执行：

```powershell
npm run dev -- --host 127.0.0.1 --port 4173
```

然后打开 `http://127.0.0.1:4173/`。运行不需要连接源站或其他互联网服务。

## 重新生成与构建

```powershell
npm run generate:pages
npm run build
npm run test:sites
```

页面生成器只读取仓库 `.tmp/seabox-ui-capture/capture/crawl-summary.json` 中的脱敏采集清单。已经生成的 HTML、页面清单和生产构建不依赖该临时目录。

## 边界

- 桌面端保真以 1440×900 与 1200×900 的源站证据为准。
- 390×844 是为防止窄屏破版而实现的推导适配；源站移动视口因内网连接中断未能重新验证。
- 新建、删除、审批提交、上传、发布等按钮只表达前端状态，不执行后台操作。
- 品牌图形根据用户提供的源截图本地重建；头像为生成的模拟景观图片。
